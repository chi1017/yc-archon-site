Case Study / 真實交案 01

iMassage 按摩工作室
網站搶救實錄.

iMassage 專業按摩是一間實際營運中的按摩工作室，官網建立在 WordPress 上，長期沒有人維護。客人反映「網站上搜尋不到想要的按摩項目」，站方才發現問題其實不只一個——這是一次真實的緊急搶救案例，沒有華麗的改版，只有把「壞掉的東西修好」。

「接手時最先看到的是站內搜尋完全沒有反應。往下挖才發現，這只是冰山一角。」

Diagnosis / 進場時的狀況

6 個同時存在的問題.

站內搜尋完全故障

jQuery 相依載入順序錯誤，導致搜尋框輸入後沒有任何反應，客人找不到想要的服務項目。

外掛長期未更新

多個外掛版本落後官方最新版本許久，存在已知的相容性與安全性風險。

閒置佈景主題拖慢網站

後台留有數個未使用的舊佈景主題檔案，佔用空間也拖慢後台管理效能。

PHP 指令設定錯誤

伺服器層級的 PHP 設定有誤，是造成部分功能異常的根本原因之一。

沒有自動化備份機制

網站沒有排程備份，一旦出狀況等於沒有安全網，資料隨時可能救不回來。

PHP 版本落後（8.2）

執行環境版本老舊，同時是資安疑慮與效能瓶頸，也會逐漸失去外掛相容性。

Resolution / 搶救流程

從診斷到驗收，5 個步驟.

01
問題定位
追蹤 jQuery 載入順序，找出搜尋功能失效的真正原因，而不是頭痛醫頭。
02
核心故障修復
修正 jQuery 相依與 PHP 指令設定，讓站內搜尋恢復正常運作。
03
環境清理與更新
更新所有外掛版本，移除閒置佈景主題，把後台整理乾淨。
04
升級與自動化
PHP 8.2 升級至 8.3，並設定 cron job 排程自動備份，補上安全網。
05
健康度驗收
用 WordPress 網站狀態工具全面複檢，確認沒有遺漏。

iMassage 官網

✦ 真實案例 網站搶救 / WordPress 閱讀時間約 6 分鐘

iMassage 專業按摩是一間實際營運中的按摩工作室，官網建立在 WordPress 上，已經好一段時間沒有人特別去維護。真正讓店家意識到「網站可能出問題」的，是客人反映的一句話：在網站上打了想要的按摩項目名稱，搜尋卻完全沒有結果。店家一開始以為只是網路不穩，直到我們接手檢查，才發現搜尋功能其實是真的壞了，而且壞掉的不只有這一件事。

掉進「看起來還好」的陷阱

這類案子最容易被忽略的地方，是網站表面上看起來還能開、還能瀏覽，店家很容易誤以為「應該沒什麼大問題」。但站內搜尋故障，對一間靠服務項目導流的按摩工作室來說影響很直接：客人找不到想要的服務，很可能就直接關掉網頁、改找別家。我們接手後做的第一件事，不是急著改版，而是先把整個網站從前台到後台完整檢查一輪，列出所有正在發生、但店家自己還沒發現的問題。

為什麼小型店家的網站最容易演變成這樣

這種狀況在中小型店家的官網其實很常見：網站剛上線的時候一切正常，但上線之後沒有人固定回頭檢查，外掛與佈景主題版本就停留在建站當下，PHP 版本也跟著伺服器環境一起放到過期。問題通常不是一次爆發，而是一點一點累積——先是某個外掛跟新版 WordPress 不相容，接著是某個功能開始跑不順，最後才輪到客人自己發現「怎麼搜尋不到」。等店家自己察覺問題時，往往已經不只一個地方出狀況，iMassage 就是很典型的例子。

診斷：同時存在的 6 個問題

檢查下來，站內搜尋失效只是其中一個症狀，實際上網站同時存在六個問題：站內搜尋完全故障，追查後發現是 jQuery 相依載入順序錯誤，導致搜尋框輸入後沒有任何反應；多個外掛版本落後官方最新版本許久，存在已知的相容性與安全性風險；後台留有數個未使用的舊佈景主題檔案，占用空間也拖慢後台管理效能；伺服器層級的 PHP 設定有誤，是造成部分功能異常的根本原因之一；網站完全沒有排程備份機制，一旦出狀況等於沒有安全網；執行環境使用的 PHP 版本落後（8.2），除了效能瓶頸，也會隨著時間推移逐漸失去外掛相容性、增加資安風險。這六個問題彼此獨立，卻同時存在同一個網站上——這也是很多長期沒人維護的官網會走到的狀態：不是突然壞掉，而是慢慢累積到某天客人反映了，店家才發現。

修復不是頭痛醫頭：5 個步驟從根本解決

搜尋功能故障只是表面症狀，如果只針對搜尋框本身修修補補，過陣子類似的問題還是會用別的形式再冒出來。我們的做法是照順序把根本原因處理掉：第一步是問題定位，追蹤 jQuery 的載入順序，找出搜尋功能失效的真正原因，而不是頭痛醫頭；第二步進行核心故障修復，修正 jQuery 相依與 PHP 指令設定，讓站內搜尋恢復正常運作；第三步是環境清理與更新，把所有外掛版本更新到位，並移除閒置的舊佈景主題，讓後台乾淨許多；第四步是升級與自動化，把 PHP 從 8.2 升級到 8.3，同時設定 cron job 排程，讓網站從此有了自動備份的安全網；最後一步是健康度驗收，使用 WordPress 內建的網站狀態工具做全面複檢，確保沒有遺漏的問題。

驗收與長期的安全網

複檢後，原本列出的六個問題全數排除，WordPress 網站狀態工具只剩下一項「可自行決定是否處理」的建議事項，不影響網站正常運作。搜尋功能完全恢復，客人可以正常搜尋到想要的按摩項目；PHP 版本從 8.2 升級到 8.3；最重要的是，網站第一次有了自動化備份機制——這是修復前完全不存在的東西，也是往後就算再發生問題，都不會演變成「資料救不回來」的最壞情況。

給還在用舊網站的店家：三個提醒

這個案子其實很有代表性，很多在地店家的官網都處在類似狀態：網站堪用，但已經好一段時間沒人檢查。如果你也是這樣，有三件事值得定期確認：第一，外掛與佈景主題是不是已經很久沒更新，過舊的外掛是資安漏洞最常見的來源；第二，網站有沒有自動備份機制，沒有備份的網站，一旦出事就是從零開始；第三，執行環境（PHP 版本、伺服器設定）是不是還跟得上目前的官方建議版本。建議至少每半年安排一次這樣的健檢，不用等到客人反映才發現問題。這些檢查通常不需要大改版，但需要有人願意真的打開後台仔細看一輪——這正是我們在做網站健檢與搶救服務時，最常幫店家找出來的問題類型。

✦ 真實案例 品牌形象網站 / 商業攝影 閱讀時間約 6 分鐘

小方光影設計是一個位於高雄左營的商業攝影團隊，成軍將近 20 年，團隊拿過國際攝影獎項，同時經營三個地點的工作室。這樣的資歷放在同業裡並不常見，但也帶出一個很實際的問題：20 年累積下來的作品、影片、教學課程、三個工作室的資訊，要怎麼放進同一個網站，還讓人看得懂、找得到？這是我們接下這個案子時，最先要解決的課題。

20 年資歷，要怎麼放進一個網站裡

資歷深的工作室常見的網站問題不是「內容不夠」，而是「內容太多、太雜」。作品集橫跨不同拍攝類型，還有影片作品、教學課程、團隊介紹、三個工作室的據點資訊——如果全部塞進同一個頁面，訪客反而會不知道該從哪裡開始看。我們的做法是先把內容盤點清楚，依照訪客最常見的幾種需求（想看作品、想了解團隊、想上課、想知道工作室在哪）重新拆分成獨立的頁面架構，而不是硬塞進一頁式網站裡。

用分類架構，讓不同類型的客戶各自找到路

攝影工作室的網站，最終目的是讓對的客人快速找到他要的東西：新人想找婚紀作品，品牌想找商業形象作品，學生想找攝影課程資訊，這幾種訪客要看的內容完全不一樣。網站最後採用完整多頁架構，把攝影作品集依類型分類展示，影片作品另外獨立呈現，團隊介紹、攝影教學課程與三個工作室的資訊也各自有清楚的頁面，讓每種訪客都能照自己的需求找到對應的內容，而不用從頭滑過所有東西。

影片作品與跨裝置瀏覽

攝影工作室的作品說服力，很大一部分來自影片——拍攝花絮、動態作品往往比靜態相片更能展現團隊的手法與現場氛圍。網站把影片作品獨立成一個區塊呈現，不跟靜態作品集混在一起，同時整站採用響應式設計，確保不管是在手機上滑動瀏覽作品集，還是在桌機上仔細端詳細節，畫面跟操作都能維持一致的品質。這對經常需要在手機上把作品連結直接傳給客人參考的攝影師來說，是很實際的需求，也是我們每個案子都會落實的基本規格。

三地工作室與教學課程：不只是拍照，還是品牌事業

三個工作室據點跟自己的教學課程，代表這已經不只是接案拍照，而是一個有規模的品牌事業。網站在資訊架構上也反映了這件事：工作室資訊需要清楚交代地點、方便客人判斷該找哪一個據點；教學課程則需要獨立的介紹頁面，呈現課程內容與定位，跟接案拍攝的商業攝影作品集區隔開來，避免混在一起讓訪客搞不清楚這個品牌到底在做什麼。

團隊介紹：把 20 年資歷變成信任感

對客人來說，願意把重要場合（婚紗、商業形象、品牌宣傳）交給一個攝影團隊，很大一部分是建立在信任上。20 年資歷、國際獲獎紀錄，這些都是實實在在的優勢，但如果只是條列在「關於我們」的一小段文字裡，很容易被訪客滑過去。網站把團隊介紹獨立成專屬頁面，讓資歷、得獎紀錄與團隊成員有足夠的篇幅被好好呈現，而不是被壓縮成首頁角落的一句話。

SEO 與長期能見度

案子裡也包含全站的 SEO 優化，讓網站架構本身對搜尋引擎友善——包括頁面的語意化結構、清楚的標題階層，讓「高雄商業攝影」「左營婚紗攝影」這類客人真正會搜尋的字詞，能對應到網站上正確的內容頁面，而不是全部擠在同一個首頁裡互相稀釋。對經營多年、口碑已經累積一定基礎的工作室來說，這是把既有的品牌資歷，轉換成長期自然搜尋流量的關鍵一步，也比從零開始經營一個新品牌要更快看到效果。

給攝影工作室與創意工作者的建議

如果你也是資歷深、作品量大的攝影工作室或創意工作者，網站規劃上有幾件事值得優先考慮：先盤點內容再決定架構，不要急著套版；把不同類型的作品或服務拆開呈現，而不是全部塞進同一頁；如果有多個據點或額外的服務（像教學課程），給它們各自獨立、講得清楚的頁面。內容夠多、夠好，架構清楚，才有辦法真正被看見、被記住。
